# EDF Zen Flex Card

Carte Lovelace pour visualiser les données de l'intégration **EDF Zen Flex** dans Home Assistant.

> **État du projet :** préparation de la première version bêta. La carte n'est pas encore disponible à l'installation depuis ce dépôt.

## Fonctionnalités prévues

- Affichage des journées **Éco**, **Sobriété** et **Bonus**.
- Calendrier mensuel interactif.
- Compteurs annuels des différents types de journées.
- Tarifs heures pleines et heures creuses, avec mise en évidence de la période en cours.
- Icônes adaptées au type de journée et à la période tarifaire.

## Intégration requise

Cette carte utilise les entités fournies par [EDF Zen Flex pour Home Assistant](https://github.com/AuroreVgn/edf-zen-flex).

## Installation

Les instructions d'installation via HACS seront publiées avec la première version bêta.
